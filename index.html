What goes where — the 5 tiles explained

Standardize & Scale

Improve proven work so it becomes repeatable and scalable. E.g., automation, standards, reusable processes.

Build the Future

Create new capabilities or solutions for long-term impact. E.g., new platforms, AI solutions, future architecture.

Run the Business

Complete work that keeps current business and delivery running. E.g., customer support, bug fixes, releases.

Pilot & Improve

Test ideas and make improvements through quick learning. E.g., prototypes, feature pilots, UX testing.

Administrative Activity

Complete essential internal and operational tasks. E.g., meetings, timesheets, training.

Examples by role

Not sure which tile your work falls under? Find your role below for concrete examples of how to log a typical week.

Engineer / Developer

Standardize & Scale — Automating a manual deployment step, writing a reusable internal library, setting coding standards.
Build the Future — Building a new microservice or platform, prototyping an AI-powered feature.
Run the Business — Fixing a production bug, on-call support, shipping a release.
Pilot & Improve — A/B testing a new algorithm, building a proof-of-concept for feedback.
Administrative Activity — Standups, sprint planning, timesheets.

Product Manager

Standardize & Scale — Creating a reusable PRD template, documenting a repeatable roadmap process.
Build the Future — Defining next-gen product vision, scoping a new market opportunity.
Run the Business — Triaging customer feedback, prioritizing the bug backlog, answering stakeholder questions.
Pilot & Improve — Running a feature pilot with select customers, analyzing pilot results.
Administrative Activity — Roadmap reviews, status reports, 1:1s.

Designer

Standardize & Scale — Building or maintaining the design system / component library.
Build the Future — Designing a new product concept or exploring a future UX direction.
Run the Business — Fixing UI bugs, supporting an in-progress feature release.
Pilot & Improve — Running usability tests, iterating a prototype based on feedback.
Administrative Activity — Design reviews, sprint planning.

QA / Support

Standardize & Scale — Building an automated test suite, writing reusable support documentation/FAQs.
Build the Future — Designing the test strategy for a new platform.
Run the Business — Handling customer tickets, running regression tests, resolving bugs.
Pilot & Improve — Piloting a new support tool, testing a new feature flow before rollout.
Administrative Activity — Ticket triage meetings, reporting metrics.

Data / Analyst

Standardize & Scale — Building a reusable dashboard template or reporting pipeline.
Build the Future — Building a new data platform/pipeline, exploring a new ML model.
Run the Business — Answering ad-hoc data requests, maintaining existing reports.
Pilot & Improve — Running an A/B test analysis, testing a new metric definition.
Administrative Activity — Data governance meetings, documentation.

Manager / Lead

Standardize & Scale — Creating a team playbook, scaling the onboarding process.
Build the Future — Defining team strategy, planning a new initiative.
Run the Business — Unblocking the team, handling escalations, performance reviews.
Pilot & Improve — Piloting a new team process and gathering feedback.
Administrative Activity — 1:1s, timesheets, budget/headcount admin.
